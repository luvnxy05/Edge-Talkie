## 2. 软件功能说明（摘要）

端语是一款运行于 HarmonyOS NEXT 设备的本地大语言模型对话应用，主要功能：

1. **本地推理对话**：基于阿里巴巴 MNN 引擎在设备端推理 4-bit 量化大模型（Qwen3/Qwen2.5 系列），无需云端，对话内容不出设备
2. **多模型管理**：应用内下载、切换、删除模型（433MB ~ 1.2GB）
3. **流式输出**：逐 token 打字机式生成，思考链折叠展示
4. **多轮对话**：上下文记忆 + 历史会话持久化
5. **本地 API 服务**：OpenAI 兼容接口（/v1/chat/completions），供同设备智能体接入
6. **推理统计**：显示 token 数与生成速度
7. **参数设置**：温度、思考模式开关

## 3. 技术特点

- 纯本地推理：无云端依赖，隐私数据不出设备
- NAPI 桥接：C++（MNN 引擎）↔ ArkTS（UI）跨语言调用
- 4-bit 量化模型：433MB 起，适配移动端内存
